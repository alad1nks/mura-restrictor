# Mura Restrictor

Telegram-бот на Python: удаляет сообщения, которые **@username пересылает в беседу**, независимо от исходного автора. Обычные сообщения @username и пересылки других участников остаются.

Проверяется отправитель сообщения в беседе (`from_user`), а наличие пересылки определяется по `forward_origin`. Работает с текстом, фото, видео, документами и другими пересланными сообщениями, включая скрытого исходного автора. Элементы альбома Telegram присылает отдельно — бот удаляет каждый из них.

## Запуск

Нужен Python 3.10 или новее.

1. Создайте бота через [@BotFather](https://t.me/BotFather) командой `/newbot` и получите токен.
2. Подготовьте окружение в папке проекта:

   ```sh
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install -e .
   cp .env.example .env
   ```

3. Впишите токен в `.env`:

   ```dotenv
   TELEGRAM_BOT_TOKEN=ваш_токен
   TARGET_USERNAME=username
   ```

4. Добавьте бота в беседу и назначьте администратором с правом **удалять сообщения**. Бот-администратор получает сообщения участников даже при включённом Privacy Mode.
5. Запустите:

   ```sh
   python -m mura_restrictor
   ```

Процесс должен постоянно работать на вашем компьютере или сервере. Для остановки нажмите Ctrl+C. Один токен должен использоваться только одним запущенным экземпляром этого бота; запуск polling отключает существующий webhook этого токена.

## Настройка и ограничения

- По умолчанию правило действует во всех группах и супергруппах, куда добавлен бот. Личные чаты и каналы не обрабатываются.
- Можно задать `TARGET_USER_ID` — числовой Telegram ID пользователя. Он имеет приоритет над `TARGET_USERNAME` и продолжает работать после смены username. Без него правило следует текущему владельцу имени `username`.
- Если сообщение отправлено анонимным администратором или от имени канала, Telegram не раскрывает личность отправителя; такие сообщения бот пропускает.
- Пересылка со скрытым именем исходного автора поддерживается, если Telegram сохраняет `forward_origin`. Копии текста и сообщения, отправленные без признака пересылки, отличить от обычных невозможно.
- Бот обрабатывает поступающие обновления, а не историю беседы. Telegram обычно разрешает удаление сообщений младше 48 часов и хранит необработанные обновления не дольше 24 часов.
- Сетевые ошибки и ограничения частоты повторяются до трёх попыток. Ошибки удаления записываются в журнал; содержимое сообщений и токен не журналируются приложением.
- `.env` исключён из Git. Не публикуйте токен и не добавляйте его в код.

## Проверка

```sh
python -m unittest discover -s tests -v
```

Тесты не обращаются к Telegram. После настройки проверьте в тестовой беседе: пересылка от @username удаляется, его обычное сообщение остаётся, пересылка другого участника остаётся.
